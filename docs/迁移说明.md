## 二、Python 3.14 兼容性结论（已检查）

**结论：完全兼容，可以直接在 3.14 上运行。** 依据：

| 检查项 | 结果 |
|---|---|
| 3.12 移除的模块（distutils / imp） | 无使用 ✓ |
| 已废弃 API（collections.Mapping / asyncio.get_event_loop / pkg_resources） | 无使用 ✓ |
| 语法特性 | 只用 3.10 语法（`str \| None`、`list[str]`），26 个文件带 `from __future__ import annotations`（延迟注解求值，3.14 兼容）✓ |
| 依赖 | 全部无上限约束（`pytest>=7`、`openai>=1` 等），3.14 下会装最新版（2026 年均已支持 3.14）✓ |

**唯一潜在风险（不影响结论）**：openai SDK 的 C 扩展依赖（如 `pydantic-core`）在 3.14 上需要对应 wheel。
若 `pip install` 遇到编译报错：换用最新版（`pip install -U openai pydantic`）或先装稳定版再升级。

> 保守起见 3.11 / 3.12 也完全没问题；3.14 直接跑即可。

## 四、框架迁移步骤

1. **拷贝**项目目录（桌面 zip 或直接拷），**不要拷 `.venv`**；
2. 新电脑装 Python 3.14 → 建 venv → 按上节装依赖；
3. **设环境变量**（照 `.env.example`，重点）：
   ```powershell
   $env:LLM_TEST_MODE="real"; $env:LLM_PROVIDER="openai"
   $env:LLM_BASE_URL="https://newapi.gosuncn.com/v1"; $env:LLM_API_KEY="裁判key"
   $env:DIFY_BASE_URL="http://127.0.0.1/v1"; $env:DIFY_API_KEY="app-xxx"
   $env:FASTGPT_BASE_URL="http://127.0.0.1:3000"; $env:FASTGPT_API_KEY="fastgpt-xxx"; $env:FASTGPT_APP_ID="24位ID"
   ```
4. **冒烟**：`.\.venv\Scripts\python -m pytest tests/`（Mock 10 条，验证框架本身 OK）；
5. 平台验证：`uv run python examples/dify_bot/probe_dify.py`（需要 Dify 环境）。

## 八、常见坑

| 坑 | 处理 |
|---|---|
| `localhost` 不通、`127.0.0.1` 通 | 环境 IPv6 `::1` 问题，统一用 `127.0.0.1` |
| FastGPT 上传报 s3_upload_network_error | hosts 加 `127.0.0.1 fastgpt-minio` |
| 知识库索引下拉空 | bge-m3 必须登记为 Embedding 类型，走 Ollama 渠道 |
| 真实模型慢 / 超时 | 分批跑 / `ci_run.py`（超时 900s + 重试 1 次） |
| 内存不足 | 一次只跑一个平台；16GB 推荐 |
| `pip install` 在 3.14 报编译错 | 升级 `pip install -U openai pydantic` 或用 3.11/3.12 |
