# 里程碑 12 独立压测执行器实施计划

## 1. 配置与模型（TDD）

- 新增 `qe_platform/loadtest/models.py`：配置、采样结果、汇总指标与序列化模型。
- 新增 `qe_platform/loadtest/config.py`：安全加载并校验 YAML，支持 HTTP/SSE、并发、
  请求数、预热、超时和输出路径。
- 先写配置/模型失败测试，再实现最小数据模型和确定性分位算法。

## 2. 异步执行器（TDD）

- 新增 `qe_platform/loadtest/runner.py`，使用 `httpx.AsyncClient`、信号量和任务收集。
- 实现普通 JSON 与 SSE 解析、TTFT、429/超时/中断分类、会话隔离和 usage/cost 提取。
- 先用本地 FastAPI 测试服务写红测，再实现执行器，验证并发不超过配置上限。

## 3. 聚合与报告（TDD）

- 新增 `qe_platform/loadtest/metrics.py` 与 `reporting.py`，输出 JSON 和自包含 HTML。
- 覆盖吞吐、错误率、429、流式中断、延迟/TTFT 分位、Token、成本和状态码。
- 报告字段不含 API key、Authorization 或完整请求消息。

## 4. CLI、文档与打包

- 在 `pyproject.toml` 注册 `llmtest-load`。
- 增加示例配置、README/使用手册运行说明和 CI 中的离线压测测试。
- CLI 的运行时错误、配置错误和报告写入错误具有明确非零退出码。

## 5. 验收与交付

- 定向测试、全量 pytest、compileall、diff check、CLI smoke。
- Docker Compose 启动 Reference Agent，执行小规模 HTTP/SSE 本地压测并留存报告。
- 更新开发流程状态表，提交、推送、PR、Actions、独立审查、合并 master、Release，
  并在 Issue #40 记录部署追踪和剩余云端风险。
